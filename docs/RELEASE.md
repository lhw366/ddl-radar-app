v2.3.9-rc.1 · 课表安全导入与表单体验候选版

修复照片课表导入后与已有课程叠在同一时段的问题。照片识别默认使用「只补空缺」：
已有课程与上课时间保留，重复课程和同周冲突课程跳过，最后只显示一条导入汇总。
导入汇总和普通操作提示提供明确的关闭按钮。
「替换当前课表」需要在识别预览中明确选择；取消预览不会修改课程或上课时间。

- 全新安装的课表为空，仅提供通用上课时间。北大作息为可选时间模板；管理员参考
  课表只在本机管理员工具中显示，已有课程时拒绝导入。
- 导入和手动保存均检查星期、节次与单双周：同一时间的单周课和双周课可并存，
  与每周课发生冲突时阻止新增。课表按格内课程排列，避免已有数据互相覆盖。
- 上课时间支持 4—20 节，可编辑并随恢复包保存。课表截图中的课程名、教室、
  备注分别解析，并使用实际图片的课程色块确定跨度；识别不确定的文字保留核对提示。
  图片缺失的上课时间标记为待设置，补全前不按其他学校的默认时间提醒。
- 事项编辑页可纵向滚动，支持从顶部下拉、从左侧向右滑返回；日期与时间使用
  应用内选择器，沿用当前主题与透明背景；打开时释放文字输入焦点，小屏可滚动至确定按钮。
- 四季顶部提醒支持上滑收起，点击内容打开应用并定位对应事项或课程，关闭按钮
  和原有关闭时长选项保留。每张提醒单独处理，其他同时到点的提醒继续显示。
- 新增本机昵称、ID、普通模式与管理员测试工具。新安装默认普通模式，已有安装
  保留测试能力；可关闭测试工具，事项与课表继续保留。
- APK 的「保存恢复包」改用 Android 系统文件保存窗口，由用户选择本地位置；
  文件实际写入成功后才提示保存完成。取消、空间不足或写入失败时保留本机数据。
- 反馈可复制或打开 GitHub Issue 草稿，由用户确认提交；只包含填写的反馈、
  应用版本与设备信息，不自动附带事项、课表、账号 ID、图片或诊断。

「本机账号」保存在当前安装的数据中，没有云端登录与跨设备同步。卸载、清除数据
或更换手机前，请先将「保存恢复包」生成的 JSON 文件保存到应用以外的位置；随后
通过「恢复账号」导入。恢复包会替换当前数据，请先备份当前事项与课表。

本版沿用 build 110 的原生提醒排期与静音触觉策略，并扩展四季横幅的操作方式。
原生界面、OCR 与备份有改动，调度器及手机电池设置保持原样；OPPO 后台到点时效
仍须实机验收。140 项功能检查与 Android 36 完整回归通过，已发布为 build 116。
详情见 [本版验收记录](https://github.com/lhw366/ddl-radar-app/blob/main/docs/local-verification-v239.md)
及 [检查与发布 workflow](https://github.com/lhw366/ddl-radar-app/actions/runs/40796182160)。
