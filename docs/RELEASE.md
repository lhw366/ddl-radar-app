v2.3.3：修复 v2.3.2 在系统静音时主动拦截原生震动的回归。OPPO 实际诊断中闹钟已送达、服务已启动，却在调用震动 API 前以 ringer_silent 返回；通知音量为 0 不再被当成禁用震动的理由。

“手机静音时震动”默认开启，可单独关闭。静音时只请求计时提醒的触觉效果，不使用闹钟音频、不修改任何音量；App 的“静默”仍关闭全部提醒。响铃始终遵守手机静音、震动模式、通知音量与勿扰，静音时禁止播放。勿扰不被触觉路径提升绕过。偏好随普通任务所有梯度、截止、课程、5/60 秒测试、周期续排与冷进程恢复持久保存。

系统静音使用独立无声视觉通道，避免通知与原生触觉重复；诊断区分用户选择静默、应用按勿扰未请求和实际 API 请求，不再把静音模式本身标成故障。不使用后台轮询、不关闭电池优化、不申请省电白名单，输出结束释放短时服务与唤醒锁。

APK 的换皮肤、完成任务与前台补弹反馈也统一经过原生静音策略，不再使用可能走媒体音量的 WebAudio 或独立 navigator.vibrate。接口异常时不会退回浏览器声音；网页环境保留原有交互反馈。

修复设置页的长下拉框、滑块、诊断文本撑宽页面；增加左右滑动切换主板块，竖向滚动、表单、课表横向滚动与弹层保持各自操作。浅色按钮文字根据背景计算对比色，壁纸上的文字使用清晰承载面，避免浅色照片下白字看不清。主题和壁纸变化时更新，不做定时轮询。
