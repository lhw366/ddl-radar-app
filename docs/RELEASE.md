v2.3.7-rc.2 · 提前投递恢复候选版

修复提醒提前进入服务时直接被丢弃的问题。本版本仍需手机验收，不代表厂商后台延迟已经解决。

- 发现提前送达时，以同一个令牌重新排入单次系统精确闹钟，保留真正的到点提醒；不持有服务等待截止，不增加并行备份闹钟。
- 每次提醒的令牌使用完整事件 ID 和到点时间。编辑和取消会使旧令牌失效，已经进入系统队列的旧参数也不能重新触发已移除的事项。
- 取消时只查找已有令牌，避免改写在途参数。更新后自动迁移旧排期。
- 诊断分别保留最后成功派发和最后入口的到点时间，并显示提前投递恢复状态；之前测试的观测不再用于解释另一条普通任务。
- 保留静音时默认震动、关闭静音震动的选项及静音禁声规则。不修改电池优化、音量或勿扰，不增加后台轮询或长期唤醒锁。

检查包含提前服务回调、真实到点后的单次派发、重复提前回调的有限恢复、修改/取消、旧版迁移，以及普通五分钟梯度、截止和后台宿主场景。以对应构建的 Actions 结果为准。

可覆盖安装。验收请使用普通任务的梯度和截止，按 Home 后观察两次提醒。具体时效需由手机记录确认，模拟器通过不代替真机结果。
