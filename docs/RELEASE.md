v2.3.7-rc.3 · 临近提醒保护候选版

修复临近提醒在退出页面或提前唤醒后过早结束服务、随后仍需重新启动入口的缺口。本版本仍需手机验收，不能以模拟器结果代替厂商手机时效。

- 保存临近三分钟内的提醒时，先确认原生短时服务已准备，再返回排定结果；切后台也核对临近事项。普通梯度、课程、截止与测试使用同一机制。
- 有效提醒提前进入服务后，在有限窗口内等待真实到点，不再立刻退出。系统闹钟保留，已运行的服务也能执行一次本地到点回调，共用同一去重与取消记录。
- 等待时不持有 CPU 唤醒锁、不轮询、不播放保活音频。没有临近事项、移除/改到远期或保护期限结束后退出；保留用户手动留存横幅的既有行为。
- 远期任务不启动等待服务，仍由系统闹钟负责唤醒。不修改电池优化、静音、音量或勿扰，不保证在任何厂商限制下都能按时唤醒。
- 诊断显示保护等待状态和真实派发入口；提前重排后若仍迟到，不再显示为后台验收成功。

检查新增故意撤掉系统回调后的真实保存、Home 和到点派发，等待不持 CPU 锁、远期不常驻、修改取消、迟到回调去重，并保留普通五分钟梯度、截止和冷/冻结进程场景。以对应构建的 Actions 结果为准。

可覆盖安装。验收请使用普通任务的梯度和截止，按 Home 后观察两次提醒。具体时效需由手机记录确认，模拟器通过不代替真机结果。
