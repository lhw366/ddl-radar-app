v2.3.1：正式 Release 签名包，沿用旧证书，可覆盖升级。CI 验签并拒绝可调试生产包。

后台震动改由系统通知通道执行，区分响铃、震动与横幅的 8 种组合；通知被拒绝时，再由有限前台派发服务尝试震动兜底。没有悬浮窗权限也保留系统通知提醒。

修复 Android 16 自动分组给后续通知加上静默标记的场景，改为显式分组，由每条提醒触发通知效果。已授权自定义悬浮横幅时，系统通知保留震动并避免重复弹出遮挡。APK 通知权限按钮改为读取原生状态，修正误报“不支持系统通知”。

增加未知来源权限受限的应用信息页入口，以及签名、安装来源、后台受限状态、通知震动开关等诊断。签名不能自动解除系统对未知来源应用的权限限制；请依照手机实际提供的“允许受限设置”选项自行确认。

检查覆盖：真实任务保存后退到桌面，禁用悬浮窗情况下的五分钟前梯度及截止提醒；通知被拒绝时的有限服务；独立开关、现有横幅、周期续排和课表。模拟器不能确认 OPPO 真机硬件震动；仍需手机诊断判断系统是否实际派发或拦截。

保留 13 时段参考课表一键导入和前台限频更新提示。不关闭手机省电策略，无后台轮询或永久 CPU 唤醒锁。
