v2.4.0-rc.1 · 邮箱账户与云端同步候选版

新增邮箱注册、验证邮件、密码登录、找回密码和云端事项/课表同步。
登录后需主动选择开启同步；游客模式和已有本机数据继续保留。

- 接入 Supabase Auth，手机上的登录凭据使用 AndroidKeyStore 加密并排除设备备份。
- 同步范围为事项、课表、昵称；壁纸照片、手机提醒偏好、诊断和反馈草稿留在本机。
- 不同账户与游客使用独立本机工作区。退出恢复游客数据；重新登录可恢复该账户未同步的本机修改。
- 云端保存检查版本号，多设备同时修改时提示选择，不静默覆盖。替换前保存本机副本，云端保留最近五次历史。
- 同步仅在前台、数据变化及网络恢复时进行，不增加后台轮询或电池优化授权。
- 沿用现有系统提醒排期、静音触觉和四季横幅；云端故障不阻塞本机保存与普通梯度提醒。

本项目数据库与邮箱回跳地址已配置，先用 Supabase 项目成员邮箱测试。面向学生开放注册前还需配置自有 SMTP。
本候选版的代码检查不等于真实邮件投递或 OPPO 实机验收通过。
配置、同步范围、数据恢复与验收步骤见 docs/supabase-setup.md。
