v2.3.8-rc.1 · 提前回调时钟补偿与四季弹窗候选版

实机日志显示，ColorOS 可能提前触发普通提醒，随后对 `exact_elapsed_recovery`
施加空闲频率限制，造成一分钟提醒数分钟后才出现。本版把提前回调后的替代入口
改回可唤醒的 AlarmClock，并按本次系统提前量补偿触发时刻。

- 5 秒测试、正常梯度、课程、截止和自定义提醒继续共用同一排期、去重和取消记录。
- 替代入口只重排一次，不创建重试风暴；等待期间不申请电池白名单、不轮询、不使用
  保活音频、不保持 CPU 唤醒锁。补偿上限两分钟，第二次提前回调仍会停止重排。
- 撤销精确闹钟权限时退回系统允许的 exact-idle 通道，并在诊断中标记 fallback。
- 跨应用顶部弹窗改为春、夏、秋、冬四套半透明场景配色，保留手动关闭和 5 秒自动
  关闭；不改用户壁纸或主题数据。

本地 Release 构建已通过编译；设备测试覆盖提前回调 4 项、临近保护 4 项、真实
五分钟梯度到截止、5 秒静音触觉、桌面季节弹窗绘制 2 项及 113 项功能检查。
OPPO 实机时效仍需安装后复测，模拟器结果不代替厂商系统结论。

可覆盖安装。验收请新建一个普通任务，按 Home 后观察 5 秒测试、一分钟内梯度与
截止两处是否震动并弹出季节横幅，再复制诊断确认入口是否为 AlarmClock 恢复。
